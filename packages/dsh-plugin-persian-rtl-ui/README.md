# dsh-plugin-persian-rtl-ui

نیمهٔ کلاینت افزونهٔ فارسی: متن فارسی رابط وب DSH را راست‌چین می‌کند.

## این افزونه چه می‌کند؟

هستهٔ نوشتار (پرامپت) در بستهٔ جداگانهٔ `dsh-plugin-persian-rtl` است. این بسته فقط برای رابط وب است و هیچ بخشی به پرامپت اضافه نمی‌کند.

هنگام بارگذاری صفحه، یک `<style>` تزریق می‌کند و با `MutationObserver` محتوای گفت‌وگو را دنبال می‌کند:

- هر بلوک متنی که فارسی داشته باشد، جهت واقعی خودش را می‌گیرد: اگر حروف فارسی از لاتین بیشتر باشد `dir="rtl"`، وگرنه `dir="auto"`.
- با `text-align: start` بلوک‌های فارسی به سمت راست و بلوک‌های انگلیسی به سمت چپ تراز می‌شوند؛ نشانگر فهرست و خانه‌های جدول هم خودکار آینه می‌شوند.
- بلوک‌های کد (`pre`, `code`, `kbd`, `samp`) همیشه LTR و چپ‌چین می‌مانند.
- کادر نوشتن (`textarea` و `contenteditable`) با `unicode-bidi: plaintext` رفتار می‌کند تا هنگام تایپ فارسی جهت درست باشد.
- با غیرفعال‌شدن افزونه، همهٔ جهت‌ها و کلاس‌های تزریق‌شده برگردانده می‌شوند.

## نصب

```text
plugin_manager install_bundle  target: <absolute path to this directory>
```

## بررسی

 پس از فعال‌شدن، در صفحهٔ وب گفت‌وگوها باید راست‌چین شوند. اگر صفحه از قبل باز است، گراف کلاینت از طریق HMR به‌روزرسانی می‌شود؛ در غیر این صورت یک بار صفحه را تازه کنید.

## نکته‌ها

- هیچ وابستگی، شبکه یا ابزاری ندارد.
- فقط متن فارسی را تغییر می‌دهد؛ چیدمان کلی پوسته (نوار کناری، دکمه‌ها) دست‌نخورده می‌ماند.
- برای خاموش‌کردن موقت، ردیف `persian-rtl-ui` را در `cordis.patch.yml` پروفایل با `disabled: true` بازنویسی کنید.
